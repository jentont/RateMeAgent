# Оценщик профилей

Мог Батл без баттла: бот оценивает один профиль Telegram и присылает
карточку-таблицу — семь метрик, у каждой балл из 10, сверху общий.

Метрики и формулы те же, что в Мог Батле (`scoring.py`, `naming.py`,
`photo.py`, `fragment.py` скопированы оттуда): аватар, @username, «о себе»,
подарки, их стоимость, возраст аккаунта, уровень TG.

Аккаунт-сборщик не нужен: «о себе», уровень и подарки бот берёт сам через
Bot API 9.3 (`getChat`, `getUserGifts`). Что Telegram не отдал, пишется
«нет данных» и в общий балл не идёт.

## Что умеет

**Профиль**
* себя — `/start`, кнопка «Оценить мой профиль» или `/me`;
* друга — кнопка «Оценить друга» (выбрать из контактов) или переслать
  боту его сообщение;
* в группе — ответить командой `/rate` на сообщение человека.

**Юзернейм** — прислать `@имя`, ссылку `t.me/имя` или `/u имя`. Карточка-таблица
из шести признаков (слово, произносимость, длина, символы, набор, повторы),
общий балл той же формулой, что строка «@username» в профиле, статус
(свободен / занят / занять нельзя / продаётся на Fragment) и цена.

**Поиск** — `поиск слово`, `/search слово` или кнопка «Поиск юзернейма».
Подбирает варианты вокруг слова (суффиксы, приставки, замена гласной) и
отдаёт свободные, лучшие сверху. Без слова («рандом») — короткие случайные.
Свобода проверяется по t.me **и** Fragment (логика из usernamebot): одна
заглушка t.me ещё не значит «свободно».

**Инлайн** — `@бот` в любом чате:
* пустой запрос — таблица своего профиля;
* `@имя` — оценка ника;
* `поиск слово` — список свободных, каждый можно отправить отдельно.

Инлайн надо включить в @BotFather: `/setinline` → выбрать бота → подсказка,
например `@имя или поиск слово`.

С домашнего ПК t.me может не открываться (блокировка провайдера) — тогда
все имена выходят «статус не узнать», а поиск ничего не находит. На
хостинге за границей работает как надо.

## Батл на призы (мини-апп)

Кнопка «Батл» в меню бота открывает мини-апп (`webapp/`, сервер `webapp.py`
в том же процессе, что и бот). Деньги — внутренний баланс в звёздах:

* **пополнение** — счёт Stars прямо в мини-аппе (25/50/100/250/500⭐);
* **турнир недели** — взнос `TOURNEY_FEE`, место по баллу профиля из 10,
  балл можно обновлять раз в час. В воскресенье 18:00 UTC банк делят топ-3
  (50/30/20 %). Меньше двух участников — взносы возвращаются;
* **дуэль профилей** — ставка 10/25/50/100⭐, соперник с той же ставкой,
  выше балл — забирает банк. Ничья — возврат. Заявка без соперника
  отзывается сама через сутки;
* **дуэль ников** — то же, но меряются ники. Ставить можно только свой
  текущий @username (его подписывает Telegram);
* **вывод** — подарками Telegram, которые бот покупает со своего баланса
  звёзд: 140⭐ = 100 + 25 + 15.

С каждого банка касса берёт `HOUSE_PERCENT` (15 %). `/bank` (для ADMIN_IDS)
показывает, сколько звёзд у бота и сколько держат игроки — **звёзд у бота
всегда должно быть не меньше, чем на руках у игроков**, иначе выводы встанут.

Против накрутки: балл заморожен в заявке, но перед боем ждущего
перепроверяют (раздал подарки — идёт с меньшим баллом, продал ник —
заявка отзывается), а призёров турнира перепроверяют при подведении итогов.

Все деньги идут через журнал `ledger` с уникальным `ref`: одна оплата не
зачислится дважды, итоги турнира не выплатятся дважды после перезапуска.

Для мини-аппа хостингу нужен https-адрес: впиши его в `WEBAPP_URL`, порт —
в `PORT`. Посмотреть без Telegram: `python preview_app.py` — напечатает
ссылку с подписанным тестовым входом и подставными участниками.

## Оформление

* **Меню** — баннер (`banner.py` → `assets/banner.png`) с приветствием в
  подписи и кнопками под ним, как в Мог Батле.
* **Премиум-эмодзи** — свой пак белых иконок: рисует `tools/make_icons.py`,
  бот сам создаёт набор `rateme_icons_by_<бот>` при запуске
  (`tools/upload_pack.py`). Если Telegram не пускает премиум-эмодзи — бот
  шлёт обычные.
* **Инлайн** — картинки: карточки профиля и ника, битвы и поиск в стиле
  карточки рулетки солика (`cards_glass.py`). Вызов на битву — картинка с
  кнопкой «Принять», итог встаёт на её место. Если у бота есть публичный
  https (`WEBAPP_URL`), инлайн работает как у @send: текст с большим превью
  картинки в рамке, картинки отдаёт `/img/…` сервера мини-аппа.

## Запуск

```bash
pip install -r requirements.txt
```

Скопируй `.env.example` в `.env`, впиши `BOT_TOKEN` и запусти:

```bash
python main.py
```

Пример карточки без Telegram: `python preview.py [аватарка.png]` → `data/preview`.
Проверка: `python selfcheck.py`.
